## 任务

1. 原生观察器：先以纯模型测试覆盖 UUID/tty 对应、同目录多会话、等待状态、失败/重试、中断、末行问句和稳定事件身份。实现 model.rs、rpc.rs、terminals.rs、mod.rs；本地 WebSocket 假服务验证读请求、ID 匹配、错误和断线。独立线程向应用提供快照，复用既有 Ghostty 探针。
2. 多来源用量表：先用 node:test 验证两来源、额度组、真实时长、未知/过期/刷新失败、来源过滤及切换。实现 usage-model.js，更新 manager/gauge 和窗口几何；用量不产生叫声。
3. 安装与契约：先测试配置不存在、注释/未知键、已有标题、空标题、重复安装与 CODEX_HOME。实现 Rust TOML 安装入口和 shell 脚本，更新 README/CONTEXT/协议/ADR/CI。
4. 验证交付：真实接口和 CLI、Terminal/Ghostty/tmux；用隔离目录注入状态验证渲染和声音；cargo test/check、JS 全套、语法检查、git diff --check；提交、PR、双轴审查及评审小结、CI。

## 重点失败场景

- 同目录两会话不得按 cwd 合并或错绑；标题无会话 ID（0.162.1 标题缩为 29 字符加省略号） 不创建猜测会话。
- 进程已退出、关闭终端或切换 thread 后清除旧宠物，断线恢复不重放提醒。
- 同账号多会话不累计用量，缺失和过期不得显示 0%。
- 标题配置需保留注释与其他设置，路径含空格可运行。
- 前端事件串行处理，确保重复通知不会叠窗或在旧窗口上推送状态。
